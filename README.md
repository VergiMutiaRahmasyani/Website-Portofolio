Website ini merupakan website portofolio pribadi saya, yang digunakan untuk menampilkan profil, pendidikan, serta pengalaman yang saya miliki, terkhususnya di bidang teknologi dan desain. Website ini bertujuan untuk memperkenalkan diri saya secara profesional kepada pengunjung, seperti recruiter, dosen, atau calon kolaborator.
Pada halaman utama, website menampilkan headline sambutan “Welcome to My Portfolio” sebagai pembuka. Selanjutnya terdapat beberapa bagian utama, yaitu About Me yang berisi profil singkat pemilik, Featured Project yang menampilkan beberapa proyek yang telah saya kerjakan beserta teknologi yang digunakan, Education yang menjelaskan latar belakang pendidikan saya saat ini, serta Experience yang berisi pengalaman saya dalam organisasi dan kegiatan volunteer.
Selain itu, di bagian samping juga terdapat informasi kontak singkat data diri saya seperti alamat, email, dan tautan ke media sosial seperti Instagram, LinkedIn, dan GitHub sehingga pengunjung dapat dengan mudah menghubungi pemilik portofolio. Website ini dirancang dengan tampilan yang sederhana dan profesional untuk memudahkan pengunjung memahami informasi tentang saya.
